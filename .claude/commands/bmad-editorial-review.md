Load and execute the BMad editorial review skills. This combines both structure and prose review:

- Structure review: `_bmad/core/bmad-editorial-review-structure/SKILL.md`
- Prose review: `_bmad/core/bmad-editorial-review-prose/SKILL.md`

First run bmad-init to load configuration:
```
python _bmad/core/bmad-init/scripts/bmad_init.py load --project-root .
```

Then follow all instructions in both skill files. Start with the structure review, then proceed to the prose review.
