  <behavior>
    --- InnerLoop class (inner_loop.py) per D-07..D-13, D-16..D-19 ---
    - InnerLoop.__init__(renderer: DifferentiableRenderer, sdf: np.ndarray | torch.Tensor, ref_weights: torch.Tensor, config: InnerLoopConfig | None = None):
      - Converts numpy SDF to torch (1,1,H,W) float32 on renderer._device if needed
      - Stores ref_weights detached on renderer._device
      - Stores config (defaults to InnerLoopConfig())
      - Stores target resolution from sdf shape

    - InnerLoop.optimize() -> OptimizationResult:
      - Builds stage schedule: config.stage_resolutions filtered to exclude resolutions >= target, then append target (per Assumption A2)
      - For each stage resolution:
        - Downsample SDF via F.interpolate(mode='bilinear', align_corners=False) to (1,1,res,res)
        - Snapshot params_initial = renderer.params.detach().clone()
        - Create Adam optimizer on [renderer.params] with lr, betas=(0.9,0.999), eps=1e-8
        - Run epoch loop (max_epochs per stage):
          - optimizer.zero_grad(set_to_none=True)
          - density = renderer.forward(res, res) -- alpha-over
          - additive = compute_additive_density(renderer, res, res)
          - Compute all 4 losses
          - l_total = compute_total_loss(...)
          - l_total.backward()
          - clip_grad_norm_([renderer.params], max_norm=1.0)
          - optimizer.step()
          - loss_history.append(l_total.detach().item())
          - If epoch >= min_epochs_before_convergence: check_convergence -> break if True
        - After stage: torch.cuda.empty_cache() if cuda available
        - Log stage completion via structlog
      - Return OptimizationResult with final params.detach(), stage histories, total epochs, convergence flags, wall_clock_s
