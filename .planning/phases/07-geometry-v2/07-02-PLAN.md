<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| aabbs input → build_bvh | Caller-provided int32 AABB array; must not contain NaN or negative dimensions |
| BVH cache key | Blake3 of raw bytes — shape MUST be included to distinguish same bytes, different count scenarios |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Denial of Service | build_bvh recursion on degenerate input | mitigate | max_depth=20 hard cap in build_bvh; test with 1000 identical AABBs |
| T-07-02-02 | Tampering | BVH cache stale tree | mitigate | blake3 key includes aabbs.shape and algo_version; any array change busts cache |
| T-07-02-03 | Denial of Service | Quadtree infinite split on duplicate AABBs | mitigate | depth < max_depth guard in _split_node prevents infinite subdivision |
| T-07-02-04 | Information Disclosure | BVH cache memory growth | accept | cachetools LRU with getsizeof bounds memory; eviction is automatic |
</threat_model>
