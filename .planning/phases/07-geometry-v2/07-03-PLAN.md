    - `pack_bitmap_uint32(pixel_buffer: np.ndarray) -> np.ndarray`: vectorized implementation. H, W = shape. W32 = (W + 31) // 32. For each column col: word_idx = col // 32, bit_idx = 31 - (col % 32), packed[:, word_idx] |= (ink[:, col].astype(np.uint32) << bit_idx). Return packed (H, W32) uint32.
    - `bitmap_collision(packed_a, ay_min, ax_min, a_h, a_w, packed_b, by_min, bx_min, b_h, b_w) -> bool`: compute overlap region oy0..oy1, ox0..ox1. If no overlap → False. Compute bit-shift alignment: `shift_a = ax_min % 32`, `shift_b = bx_min % 32`, `bit_shift = shift_a - shift_b`. For each overlap row: extract row slices from packed_a and packed_b for the overlap x region. If bit_shift > 0: shift B's row right by bit_shift before AND. If bit_shift < 0: shift A's row right by abs(bit_shift). Check `np.any(shifted_a & shifted_b)`.

| T-07-03-04 | Elevation of Privilege | SAT accepting placement that bitmap would reject | accept | 5-stage hierarchy means SAT failure → placement rejected before bitmap is ever called |
