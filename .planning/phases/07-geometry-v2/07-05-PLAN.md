```python
class BezierCurve(AeroCloudBase):
    # One cubic Bezier segment: P0, P1 (control), P2 (control), P3
    # All points are (y, x) float64 — D-14 coordinate convention
    p0: tuple[float, float]   # (y, x) start
    p1: tuple[float, float]   # (y, x) control 1
    p2: tuple[float, float]   # (y, x) control 2
    p3: tuple[float, float]   # (y, x) end

class BezierGlyph(AeroCloudBase):
    # Sibling to GlyphBBox — stores Bezier representation of same glyph
    font_family: str
    size_pt: int
    codepoint: int
    contours: tuple[tuple[BezierCurve, ...], ...]  # outer tuple = multiple contours (holes)
    tolerance: float   # Douglas-Peucker epsilon used (for reproducibility)
```

cv2 usage (D-16, RESEARCH.md Pattern in §GEO2-09):
```python
import cv2

def glyph_to_bezier(glyph: GlyphBBox, tolerance: float = 1.0) -> BezierGlyph:
    # 1. Convert pixel_buffer to uint8 binary: ink = (glyph.pixel_buffer > 0).astype(np.uint8) * 255
    # 2. cv2.findContours(ink, cv2.RETR_LIST, cv2.CHAIN_APPROX_SIMPLE) → raw contours
    # 3. For each contour: cv2.approxPolyDP(contour, tolerance, closed=True) → simplified polygon
    # 4. Fit cubic Bezier through simplified polygon points (catmull-rom → bezier conversion)
    # 5. Return BezierGlyph
    # NOTE: cv2 returns (x, y) points — MUST convert to (y, x) for D-14
```

Bezier fitting from polygon points:
- Simple approach: each consecutive triple of simplified polygon points → one cubic Bezier
- Control points: Catmull-Rom to Bezier conversion: P1_ctrl = P0 + (P2 - P_prev) / 6, P2_ctrl = P2 - (P3 - P1) / 6
- This is Claude's discretion for tolerance parameter default (1.0 pixels recommended by research)
- float64 for all control points (sub-millimeter precision for Phase 12 SVG/PDF export)

    Models:
    - `BezierCurve(AeroCloudBase)`: p0, p1, p2, p3 as `tuple[float, float]` — all float64 (sub-millimeter, D-19)
    - `BezierGlyph(AeroCloudBase)`: font_family, size_pt, codepoint, contours (nested tuples), tolerance

    `_catmull_rom_to_bezier(pts: np.ndarray) -> list[BezierCurve]`:
    - Input: simplified polygon points as (N, 2) float64 array in (y, x) order
    - For each consecutive group of 4 points (wrapping): compute cubic Bezier control points via Catmull-Rom formula
    - P1_ctrl = P1 + (P2 - P0) / 6
    - P2_ctrl = P2 - (P3 - P1) / 6
    - Return list of BezierCurve segments

    `glyph_to_bezier(glyph: GlyphBBox, tolerance: float = 1.0) -> BezierGlyph`:
    1. Handle empty pixel_buffer: if pixel_buffer.max() == 0 → return BezierGlyph with empty contours
    2. ink = (glyph.pixel_buffer > 0).astype(np.uint8) * 255
    3. contours_raw, _ = cv2.findContours(ink, cv2.RETR_LIST, cv2.CHAIN_APPROX_SIMPLE)
    4. For each raw contour (shape (N, 1, 2) in cv2 convention — x,y):
       a. approx = cv2.approxPolyDP(contour, epsilon=tolerance, closed=True) — shape (M, 1, 2)
       b. pts = approx.squeeze(1)  # shape (M, 2), columns are [x, y]
       c. FLIP to (y, x): pts_yx = pts[:, ::-1].astype(np.float64)  # D-14 coordinate fix
       d. bezier_curves = _catmull_rom_to_bezier(pts_yx)
       e. Append tuple(bezier_curves) to contours list
    5. Return BezierGlyph(font_family=glyph.font_family, size_pt=glyph.size_pt, codepoint=glyph.codepoint, contours=tuple(tuple(c) for c in contours), tolerance=tolerance)
