  <action>
    Create `packages/engine/src/aerocloud/outer_loop/metrics.py` with pure numpy functions:

    1. `compute_lc(density: np.ndarray, sdf_mask: np.ndarray) -> float`:
       Per D-05: `LC = sum(density[sdf_mask > 0] > 0) / sum(sdf_mask > 0)`.
       density is the rendered 2D tensor (float, 0-1 range). sdf_mask is binary (True = inside silhouette).
       Return ratio of ink pixels inside silhouette to total silhouette area. Clamp to [0, 1].

    2. `compute_lu(density: np.ndarray, sdf_mask: np.ndarray, k: int = 8) -> float`:
       Per D-05: Subdivide density into K x K grid. For each cell, compute local density = mean(density[cell_mask]). LU = 1 - std(local_densities) / (max_density - min_density + 1e-8).
       Only consider cells that overlap with sdf_mask. Clamp to [0, 1].

    3. `compute_ss(density: np.ndarray, sdf_mask: np.ndarray) -> float`:
       Per D-05: `SS = 1 - (whitespace_inside / silhouette_area)` where whitespace_inside = sum((sdf_mask > 0) & (density <= 0)).
       Clamp to [0, 1].

    4. `compute_compactness(word_positions_yx: np.ndarray, word_sizes: np.ndarray) -> float`:
       Per D-05: Build bounding boxes from positions + sizes. Compute convex hull via `scipy.spatial.ConvexHull`. `C = 4 * pi * hull.volume / hull.area**2` (in 2D, hull.volume = area, hull.area = perimeter).
       Handle degenerate cases (< 3 points → return 0.0). Clamp to [0, 1].

    5. `compute_aspect_ratio(bbox_width: float, bbox_height: float) -> float`:
       Per D-05: `phi = 1.618; actual = max(w,h)/min(w,h); AR = 1 - abs(actual - phi) / phi`. Clamp to [0, 1].

    Write tests first (red), then implement (green). Use small synthetic arrays (8x8, 16x16) for fast tests.
  </action>
