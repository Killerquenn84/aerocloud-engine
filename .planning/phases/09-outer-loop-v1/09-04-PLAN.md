  <action>
    Add to `packages/engine/src/aerocloud/outer_loop/emitter.py`:

    `async def reeval_elites(archive_wrapper: ArchiveWrapper, evaluate_fn: Callable[[np.ndarray], tuple[float, np.ndarray]], top_n: int = 10, drift_threshold: float = 0.1) -> list[ReEvalResult]`:

    Per D-14: Every `reeval_every_n` evaluations (caller controls timing), re-run the fitness evaluation on top-N elites.

    1. Get archive data via `archive_wrapper.data()`. Extract elites sorted by fitness descending. Take top_n.
    2. For each elite: call `evaluate_fn(solution)` which returns (new_fitness, new_measures).
    3. Compare: `drift_pct = (fitness_before - fitness_after) / (fitness_before + 1e-8)`.
    4. If `drift_pct > drift_threshold` (default 0.1 = 10%), flag as drifted.
    5. Log drifted elites via structlog.
    6. Return list of ReEvalResult.

    Note: This function does NOT modify the archive — the caller decides what to do with drifted elites (remove, re-add with new fitness, etc.). This keeps the function pure and testable.

    Tests use a mock evaluate_fn that returns controlled fitness values.
