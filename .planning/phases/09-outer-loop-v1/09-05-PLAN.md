  <action>
    Create `packages/engine/src/aerocloud/outer_loop/scheduler.py`:

    1. `class OuterLoopResult(AeroCloudBase)`:
       final_coverage: float, num_elites: int, best_fitness: float, total_evaluations: int, reeval_results: list[ReEvalResult], saturation_plateaued: bool.

    2. `class OuterLoop`:
       Per D-15: The full evaluation pipeline.

       `__init__(self, archive: ArchiveWrapper, evaluate_fn: Callable, persistence: ArchivePersistence | None, novelty_emitter: NoveltyGaussianEmitter, saturation_monitor: SaturationMonitor, quality_weights: QualityWeights, flush_every_n: int = 100, reeval_every_n: int = 200)`:

       `evaluate_fn` signature: `(solution: np.ndarray) -> tuple[QualityMetrics, BehaviorDescriptor, np.ndarray]` — takes a flat solution array, runs the full pipeline (unflatten → InnerLoop.optimize → compute metrics → compute descriptors), returns (metrics, bd, descriptor_embedding_384).

       The caller (production code or test) constructs evaluate_fn to wire semantic_warm_start → DifferentiableRenderer → InnerLoop → compute_all_metrics → compute_descriptors (D-15). This keeps OuterLoop testable without real InnerLoop.

       `def single_iteration(self) -> int`:
       1. `solutions = self._archive.ask()` — (batch_size, solution_dim)
       2. For each solution: call evaluate_fn → get QualityMetrics + BehaviorDescriptor
       3. Compute objectives: `metrics.combined_fitness(self._quality_weights)` for each
       4. Compute measures: `np.array([bd.shape_fidelity, bd.rotation_ratio, bd.symmetry, bd.semantic_clustering])` for each
       5. `self._archive.tell(objectives, measures)`
       6. `self._saturation_monitor.record(self._archive.coverage)`
       7. Increment total_evaluations counter
       8. If total_evaluations % flush_every_n == 0 and persistence is not None: schedule flush (collect entries, call flush_batch)
       9. If total_evaluations % reeval_every_n == 0: call reeval_elites
       10. Return batch_size (number of evaluations this iteration)
       11. Log iteration stats via structlog (coverage, num_elites, best_fitness)

       `def run(self, n_iterations: int) -> OuterLoopResult`:
       Loop single_iteration n_iterations times. Return OuterLoopResult.

       Handle Pitfall 3 (variable word count): solutions are padded to max_words * 4. The evaluate_fn is responsible for unpadding (it knows the actual word count from the layout).

    3. Tests mock evaluate_fn to return synthetic QualityMetrics and BehaviorDescriptor. Mock persistence to verify flush_batch calls. Verify iteration counting, flush timing, reeval timing.
