| Boundary | Description |
|----------|-------------|
| Celery Beat -> Task | Schedule triggers task; task reads env vars for DB DSN |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | I (Info Disclosure) | ReplayLogger DSN | mitigate | Never log DSN value; store on instance only (same pattern as ArchivePersistence T-09-07) |
| T-10-02 | T (Tampering) | SQL injection in replay | mitigate | All SQL uses $N positional parameters; no string interpolation of user-derived data |
| T-10-03 | D (DoS) | Unbounded replay events table | accept | Retention policy deferred to Phase 12; table grows linearly with nightly runs (~1000 events/night) |
| T-10-04 | S (Spoofing) | REDIS_URL env var | accept | Worker runs on trusted VPS; env var injection requires root access |
</threat_model>
