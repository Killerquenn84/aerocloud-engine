  <files>

  <behavior>
    - structure_aware_mutate(solution: ndarray shape (max_words*4,), config: SelfPlayConfig, rng: np.random.Generator) -> ndarray same shape. Reshapes to (N,4), applies sigma_per_col=[sigma_xy, sigma_xy, sigma_scale, sigma_theta], adds Gaussian noise, flattens back.
    - uniform_crossover(parent_a: ndarray, parent_b: ndarray, rng: Generator, p: float=0.5) -> ndarray. Per-element mask = rng.random() < p, np.where(mask, parent_a, parent_b).
    - sample_parents(archive_data: dict, rng: Generator) -> tuple[ndarray, ndarray]. Uniform random index selection from archive_data["solution"]. Two distinct indices if n_elites >= 2, else same index twice.
    - With seed=42 and fixed input, structure_aware_mutate produces deterministic output
    - Crossover with p=0.0 returns parent_b entirely; p=1.0 returns parent_a entirely
    - sample_parents with 1 elite returns that elite twice
  </behavior>
