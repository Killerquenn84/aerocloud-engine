    **TDD GREEN:** Implement `loop.py`:

    **SelfPlayLoop.__init__:** Store all dependencies. Initialize AdversarialReviewer with archive solutions and weights. Initialize counters (n_accepted, n_rejected). Store frozen_baseline dict.

    **SelfPlayLoop.single_iteration(iteration):**
    1. Get archive_data = self._archive.data()
    2. If rng.random() < config.mutation_ratio: sample 1 parent, apply structure_aware_mutate -> mutation_type="gaussian"
    3. Else: sample 2 parents, apply uniform_crossover -> mutation_type="crossover"
    4. Evaluate mutated solution via self._evaluate_fn(solution) -> (QualityMetrics, BD, emb_384)
    5. Compute fitness = metrics.combined_fitness(weights)
    6. Look up baseline: if frozen_baseline and bin_id in frozen_baseline: get (baseline_fitness, baseline_metrics)
    7. Run adversarial reviewer: reviewer.review(solution, metrics_new, metrics_baseline)
    8. If not accepted: return SelfPlayEvent(accepted=False, reject_reason=reason, ...)
    9. If baseline exists: check dominance `fitness > baseline_fitness + config.dominance_margin` (STRICT >). If fails: return SelfPlayEvent(accepted=False, reject_reason="dominance_margin_not_exceeded")
    10. If accepted: call archive.tell() and return SelfPlayEvent(accepted=True, ...)

    **SelfPlayLoop.run(n_iterations):**
    1. Generate run_id = uuid.uuid4(), record started_at
    2. If replay_logger: asyncio.run(replay_logger.insert_run(run_id, config.model_dump()))
    3. Load previous night's descriptor histogram via replay_logger
    4. For i in range(n_iterations): event = single_iteration(i); track n_accepted/n_rejected; if replay_logger: asyncio.run(replay_logger.insert_event(run_id, event))
    5. After loop: collect current descriptors from archive.data()["measures"]
    6. If previous histogram exists: compute KL divergence, check shift, log warning if > threshold
    7. Store current histogram in replay_logger
    8. Finalize run with stats
    9. Return SelfPlayRunResult
