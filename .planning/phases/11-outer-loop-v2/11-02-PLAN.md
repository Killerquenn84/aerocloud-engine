    - f_range = 0.9 - 0.2 = 0.7
    - delta_max = sqrt(4) = 2.0 for [0,1]^4
    - For theta=0.0: omega = f_normalized (pure quality)
    - For theta=1.0: omega = f_normalized - delta/delta_max (quality penalized by distance)

  <implementation>
    Create cqd.py in packages/engine/src/aerocloud/outer_loop/:

    1. CQDResult(AeroCloudBase):
       - cqd: float (the aggregate CQD score)
       - theta_curve: list[float] (51 values, smoothed)

    2. compute_cqd(objectives, measures, n_samples=10000, n_theta=51, seed=42) -> CQDResult:
       - Guard: if len(objectives) < 2, return zeros
       - f_min, f_max = objectives.min(), objectives.max()
       - f_range = max(f_max - f_min, 1e-8)  # Pitfall 4: prevent div-by-zero
       - delta_max = sqrt(4.0) = 2.0  # [0,1]^4 behavior space, per RESEARCH.md
       - rng = np.random.default_rng(seed)  # Fixed seed per OUTER2-05
       - ref_points = rng.uniform(0.0, 1.0, size=(n_samples, 4))  # Uniform in [0,1]^4 (Claude's discretion)
       - Use sklearn NearestNeighbors(algorithm='ball_tree') to find nearest archive elite for each ref point
       - Vectorize omega matrix [n_samples, n_theta]:
         thetas = np.linspace(0.0, 1.0, n_theta)  # shape (51,)
         f_norm = (nearest_objectives - f_min) / f_range  # shape (n_samples,)
         delta_norm = nearest_distances / delta_max  # shape (n_samples,)
         omega = f_norm[:, None] - thetas[None, :] * delta_norm[:, None]  # (n_samples, 51)
       - cqd = float(np.mean(omega))  # D-06: (1/NM) * sum
       - theta_curve_raw = np.mean(omega, axis=0)  # shape (51,)
       - Smooth: np.convolve(theta_curve_raw, np.ones(3)/3, mode='same')  # D-07
       - Return CQDResult(cqd=cqd, theta_curve=theta_curve.tolist())

    3. The function takes raw numpy arrays (not ArchiveWrapper) so it can be tested independently.
       A thin wrapper compute_cqd_from_archive(archive: ArchiveWrapper, ...) extracts data and calls compute_cqd().
  </implementation>
</feature>
