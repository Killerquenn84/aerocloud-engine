  <implementation>
    Create pareto.py in packages/engine/src/aerocloud/outer_loop/:

    1. ParetoFront(AeroCloudBase, arbitrary_types_allowed=True):
       - indices: list[int]  (indices into archive data arrays)
       - design_fidelity: list[float]  (obj1 per Pareto point)
       - packing_density: list[float]  (obj2 per Pareto point)

    2. extract_pareto_front(objectives, measures, layout_coverage, space_saving) -> ParetoFront:
       - Compute obj1 (design_fidelity): measures[:, 0] + measures[:, 2] = shape_fidelity + symmetry (D-11)
       - Compute obj2 (packing_density): layout_coverage + space_saving (D-11)
       - F = np.column_stack([obj1, obj2])  shape (n, 2)
       - Negate F for pymoo (minimization): F_neg = -F
       - fronts = NonDominatedSorting().do(F_neg)  returns list of arrays
       - pareto_indices = fronts[0]  (first front = non-dominated)
       - Return ParetoFront(indices=pareto_indices.tolist(), design_fidelity=obj1[pareto_indices].tolist(), packing_density=obj2[pareto_indices].tolist())

    3. compute_cqd_hv(objectives, measures, layout_coverage, space_saving, bins_per_dim) -> float:
       - Per D-10: CQD_HV = sum_G HV(S_HV(G))
       - For each occupied grid cell G:
         - Collect elites in that cell
         - Compute their 2D objectives (design_fidelity, packing_density)
         - Negate for pymoo minimization
         - ref_point = np.array([0.0, 0.0]) (D-10, since -F in [-1, 0] after maximization -> minimization)
         - hv = HV(ref_point=ref_point).do(-F_cell)
         - Accumulate
       - Return total HV

    4. pareto_slider(pareto_front, position, archive_data) -> dict:
       - Clip position to [0.0, 1.0] (Pitfall 5)
       - If len(pareto_front.indices) == 0: raise ValueError
       - If len(pareto_front.indices) == 1: return that elite
       - Sort Pareto front by design_fidelity descending
       - Interpolate: target_obj1 = max_df * (1 - position) + min_df * position
       -              target_obj2 = min_pd * (1 - position) + max_pd * position
       - target = [target_obj1, target_obj2]
       - Find nearest Pareto point by Euclidean distance in 2D objective space
       - Return archive entry at that index (dict from archive.data() at the found index)

    5. A thin wrapper extract_pareto_front_from_archive(archive: ArchiveWrapper) extracts data() and calls the pure function.

    CRITICAL: pymoo HV ref_point for maximization: negate objectives, use ref_point=[0.0, 0.0] (Pitfall 6 from RESEARCH).
    CRITICAL: NonDominatedSorting handles ties; for SC3 (no dominance ties), keep only unique objective pairs.
  </implementation>
