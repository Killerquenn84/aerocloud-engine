  <behavior>
    - SVG: glyph_to_svg_path on a square BezierGlyph produces valid SVG path d-attribute with M, C, Z commands
    - SVG: coordinate flip — (y=10, x=20) internal becomes "20.000000,10.000000" in SVG output
    - SVG: export_svg on list of glyphs produces valid XML with <svg> root and <path> children
    - SVG: export_svg includes width/height attributes matching canvas dimensions
    - SVG: asymmetric glyph (letter "F" shape) exports with correct orientation (not mirrored)
    - PDF: export_pdf returns bytes starting with %PDF magic bytes
    - PDF: export_pdf output length > 100 bytes (non-trivial content)
    - PDF: coordinate precision — float64 BezierCurve control points preserved at sub-millimeter (300 DPI)
  </behavior>
  <action>
    1. Write tests FIRST per behavior spec.

    2. Implement `svg_export.py` per D-03:
       - `_bezier_curve_to_svg_cmd(curve: BezierCurve) -> str` — Flip (y,x) → (x,y). Format: `C x1,y1 x2,y2 x3,y3`. Use 6 decimal places for sub-pixel precision.
       - `glyph_to_svg_path(glyph: BezierGlyph) -> str` — Iterate contours, first point is M, rest are C commands, close with Z. Join all contours into single d-attribute string.
       - `export_svg(placed_glyphs: list[BezierGlyph], width: int, height: int, colors: list[str] | None = None) -> str` — Build SVG document using `lxml.etree` (more reliable than svgelements API for document generation — per research fallback note). Set viewBox="0 0 {width} {height}". Each glyph becomes a `<path>` element with d-attribute from glyph_to_svg_path. If colors provided, set fill attribute per glyph.

       CRITICAL coordinate convention: All internal BezierCurve points are (y, x). The ONLY place the flip happens is in `_bezier_curve_to_svg_cmd`. Do NOT double-flip.

    3. Implement `pdf_export.py` per D-04:
       - Constants: `DPI = 300`, `PX_TO_PT = 72.0 / DPI` (0.24 pt/px for sub-millimeter).
       - `export_pdf(placed_glyphs: list[BezierGlyph], width_px: int, height_px: int, colors: list[str] | None = None) -> bytes` — Create ReportLab Canvas in BytesIO. Page size = (width_px * PX_TO_PT, height_px * PX_TO_PT). For each glyph: beginPath, moveTo first point (flipped y,x → x,y and scaled by PX_TO_PT), bezierCurveTo for each curve segment, closePath, drawPath with fill=1 stroke=0. Save canvas, return bytes.

       CRITICAL: Same coordinate flip as SVG — (y,x) → (x,y) — applied once per control point during path construction.

    4. Update `export/__init__.py` to export `export_svg`, `export_pdf`.
  </action>
