<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API | Untrusted HTTP requests cross into FastAPI |
| API → Celery | Validated request dict crosses into worker via Redis |
| Client → SSE | Client subscribes to progress stream; read-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05-01 | S (Spoofing) | health.py | mitigate | /health/internal requires X-Internal-Token header; public /health reveals no internals |
| T-12-05-02 | D (DoS) | render.py | mitigate | slowapi rate limiter at 10/minute per IP; Redis-backed for distributed state |
| T-12-05-03 | I (Info Disclosure) | health.py | mitigate | /health/internal returns only status booleans, not connection strings or credentials |
| T-12-05-04 | D (DoS) | render.py SSE | mitigate | SSE stream terminates on SUCCESS/FAILURE; ping timeout disconnects abandoned streams |
| T-12-05-05 | S (Spoofing) | rate_limit.py | accept | IP-based rate limiting; per-shop limiting deferred to integration with Shopify session token |
</threat_model>
