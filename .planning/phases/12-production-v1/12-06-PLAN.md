    1. Read current `infra/docker/docker-compose.yml`, `infra/docker/worker.Dockerfile`, and `infra/docker/api.Dockerfile`.

    2. Update `docker-compose.yml` — add DCGM Exporter sidecar per D-21:
       ```yaml
       dcgm-exporter:
         image: nvcr.io/nvidia/k8s/dcgm-exporter:3.6.2-3.4.2-ubuntu22.04
         runtime: nvidia
         environment:
           - NVIDIA_VISIBLE_DEVICES=all
         ports:
           - "9400:9400"
         cap_add:
           - SYS_ADMIN
         depends_on:
           - worker
         restart: unless-stopped
       ```
       Use 3.6.2 image which has the `k8s_container_name` label rename (not old `container_name`). Note: CVE-2026-2184 patched in this version.

    3. Update worker service in docker-compose.yml:
       - Add `runtime: nvidia` to worker service.
       - Add `CUDA_VISIBLE_DEVICES=0` to worker environment (D-14).
       - Add `entrypoint: ["/app/infra/docker/worker-entrypoint.sh"]` pointing to the script from Plan 03.
       - Add `stop_signal: SIGTERM` and `stop_grace_period: 30s`.

    4. Update `worker.Dockerfile` per D-23:
       - Add `STOPSIGNAL SIGTERM`.
       - Add HEALTHCHECK: `HEALTHCHECK --interval=30s --timeout=10s --retries=3 CMD celery -A aerocloud_worker.celery_app inspect ping -t 5 || exit 1`.
       - COPY `worker-entrypoint.sh` into image and `RUN chmod +x`.

    5. Update `api.Dockerfile`:
       - Add HEALTHCHECK: `HEALTHCHECK --interval=15s --timeout=5s --retries=3 CMD curl -f http://localhost:8000/health || exit 1`.
