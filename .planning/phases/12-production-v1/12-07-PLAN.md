    1. Write test FIRST in `test_golden_image.py`:
       ```python
       import pytest
       import numpy as np
       from pathlib import Path
       from PIL import Image
       from skimage.metrics import structural_similarity as ssim

       GOLDEN_DIR = Path(__file__).parent / "golden"
       SSIM_THRESHOLD = 0.95  # D-27 locked floor
       FIXTURES = ["circle", "square", "star", "crescent"]

       @pytest.mark.parametrize("fixture_name", FIXTURES)
       def test_golden_image_ssim(fixture_name: str) -> None:
           golden_path = GOLDEN_DIR / f"{fixture_name}.png"
           if not golden_path.exists():
               pytest.skip(f"Golden image not found: {golden_path}. Run generate_golden_images.py first.")
           golden = np.array(Image.open(golden_path).convert("L"))
           rendered = render_fixture(fixture_name, seed=42)
           score = ssim(golden, rendered, data_range=255)
           assert score >= SSIM_THRESHOLD, (
               f"{fixture_name}: SSIM {score:.4f} < threshold {SSIM_THRESHOLD}"
           )
       ```
       The `render_fixture` helper function:
       - Loads the mask from `packages/engine/tests/fixtures/masks/{fixture_name}.png` (these exist from Phase 4).
       - Runs the full pipeline: mask → SDF → placement → renderer → export_png → numpy grayscale.
       - Uses `set_seed(42)` before each run.
       - If full pipeline integration is not yet wired, create a simplified version that renders directly from the renderer with known word positions.

    2. Create `generate_golden_images.py`:
       - Reuses the same `render_fixture` function.
       - Saves each rendered output as PNG to `tests/regression/golden/{fixture_name}.png`.
       - Run once to generate baseline, commit the golden PNGs.
       - CLI: `python packages/engine/scripts/generate_golden_images.py`

    3. Create `__init__.py` files for regression test packages.

    4. Handle the case where the full pipeline is not yet integrated end-to-end: the golden image test can use a simplified rendering pipeline (mask + placeholder words + renderer forward pass) that still validates visual output determinism. The key is that the SAME code path runs in generation and test.
